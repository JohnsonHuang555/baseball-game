# 比賽設定記下規則版本，舊存檔照舊規則重播

比賽靠「種子 + 指令紀錄」重播（ADR-0001），所以只要模擬規則改了，打到一半的存檔重播出來就會不一樣，甚至出現已經不合法的指令（例如壘上沒人了還要盜壘）。我們在比賽設定（GameSetup）加上規則版本 `rules`：新比賽記下目前版本，模擬依版本決定要不要套用新規則；舊存檔沒有這個欄位，讀檔時標成 1，照最早的規則重播。

目前的版本：1 是原始規則；2 起 AI 守備時會佈陣；3 起有左右投打相剋；4 起 AI 會依左右相剋換投、派代打。

## Consequences

- 改動會影響比賽結果的規則時，要升版本，並讓舊版本維持原本的行為。
- 只影響畫面（例如安打的落點角度）或比賽外（例如錦標賽成長）的改動不用升版本。
- 版本 2 剛上線時沒有記版本，那段期間存的比賽讀檔時會被當成 1。為了不讓這種落差卡住整場比賽，重播時遇到不合法的指令會直接略過。
