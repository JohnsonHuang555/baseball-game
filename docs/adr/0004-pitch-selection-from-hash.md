# 配球對決：AI 的球種由「種子 + 第幾步」的雜湊決定，不抽亂數

玩家反應決勝球只有停紅線，太單調。我們把親自出手改成配球對決（規則版本 5，ADR-0003）：

- 投球：選球種（每位投手 2～4 種）、點九宮格決定位置，再照著虛線畫出球種的手勢。畫得越準越到位；投在角落、打者的弱點、換球種對投手有利，投在正中間、打者的熱區、同一個打席連投同一種球對打者有利。
- 出棒：先猜直球或變化球，猜中黃色區變寬，猜錯變窄；接著停紅線，停的位置偏下拉打、偏上推打，可以刻意打向對方佈陣空出來的那一邊。

猜球要在計量條出現前就知道有沒有猜中，因為黃色區的寬度跟著變，畫面也要告訴玩家來的是什麼球。可是亂數只能在 `step()` 裡依序抽，還沒推進就不知道下一個亂數。所以 AI 這一球的球種不抽亂數，而是用「比賽種子 + 第幾步」的雜湊算出來（再依投手的配球習慣與球數決定直球的機率）。這個值在下指令前就能算，重播時也一定一樣（ADR-0001）。

投手的球種、打者的熱區也跟慣用手一樣，由球員編號的雜湊決定，不存進球員資料，舊存檔的球員也有。

## Considered Options

- 在下指令時就先抽亂數決定球種：會讓亂數的使用順序依玩家有沒有出手而改變，同一份紀錄在不同時機重播會分歧。
- 不讓猜球影響黃色區，只在結算時判定：可以照常抽亂數，但玩家停紅線時得不到任何回饋，猜球就只是一個沒有手感的選項。

## Consequences

- 玩家如果讀得到程式碼，就能在猜球前算出 AI 的球種。單機遊戲可以接受；日後做 PvP，要改由伺服器在玩家猜完之後才揭曉。
- 手勢的準確度（0～1）跟計量條的位置一樣記進指令紀錄，伺服器只能驗證「這個準確度會得到這個結果」，無法驗證玩家真的畫得那麼準（同 ADR-0002）。
