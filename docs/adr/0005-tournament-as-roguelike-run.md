# 錦標賽改成 roguelike 的一輪，舊錦標賽存檔作廢

玩家試玩後反應：快速比賽打完沒收穫、錦標賽奪冠只拿到獎盃和裝扮很空虛、隊伍疊不起來。原本的錦標賽是 16 隊單淘汰，最多 6 場，每場之間只有選秀和成長，太短也太少選擇，養成來不及成形。

我們把錦標賽改成 roguelike 的一輪：例行賽 8 場（5 勝晉級）加季後賽 8 隊（決賽三戰兩勝），開局選起始秘技，每場後有獎勵選擇（贏 3 選 1、輸 2 選 1），例行賽中穿插休息站（商店、訓練、事件），球員可以帶裝備、覺醒潛能、學新球種。跨輪只保留不增加強度的東西（解鎖、傳奇館、球團史），不做永久能力加成，因為那會跟五級難度互相抵銷。快速比賽移除，改成不記錄結果的自由練習。

考慮過的其他做法：保留 16 隊單淘汰只多加獎勵（太短，疊不起來）；生命制（可輸 3 場）；完整的《殺戮尖塔》式地圖分支（範圍太大，休息站已經提供大部分的選擇感）；每日挑戰取代快速比賽（沒有伺服器，使用者偏好沒有紀錄負擔的沙盒）。

## Consequences

- 錦標賽存檔的結構完全不同，舊的進行中錦標賽直接作廢，首頁提示一次。冠軍紀錄與裝扮解鎖保留，轉進球團史。
- 單場比賽的重播仍照 ADR-0001、ADR-0003。裝備在開賽時直接加進比賽設定裡的能力值，模擬不用知道裝備；秘技寫在比賽設定的隊伍上，由模擬判斷效果。沒有秘技的隊伍行為跟以前完全一樣，所以不用升規則版本。
- 一輪約 13 場、1～1.5 小時，比原本長很多，所以錦標賽存檔必須能在任何兩場之間（包含休息站與獎勵選擇中）中斷再繼續。
