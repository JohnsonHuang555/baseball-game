# 打者加上本職守位，守非本職時守備打折

以前守位完全自由：任何打者都能守任何位置，只看守備值。羈絆系統需要「守位羈絆」（黃金二遊、投捕搭檔），但每支隊伍本來就一定有二壘手、游擊手和捕手，條件如果只看「有沒有人站在那個位置」，每場都會成立，不會影響選人。所以每名打者多了一個本職守位，守本職以外的位置時守備打折：同為內野或同為外野 −1，非捕手守捕手 −3，其他（內外野互換、捕手去守別的位置）−2；指定打擊不看本職。守位羈絆要求那個位置由守本職的人擔任。

另一個方案是不加欄位，改看站在那個位置的人是什麼流派（例如二游都是防守型才成立）。這個方案比較省工，但會跟鐵壁球隊的條件重複，球員卡也不會多出「守位」這個選人的考量，所以沒有採用。

## Consequences

- 開局的隨機隊伍保證八個守位各有一名本職；獎勵、商店的球員卡本職隨機（捕手少見），替換時接手被換掉那個人的守位，可能變成守非本職。
- 本職跟擊球方向、慣用手一樣由球員編號推算，不多抽亂數，同一個種子產生的隊伍不變。
- 舊存檔補欄位時，先發陣容裡的人把目前的守位當本職，打到一半的錦標賽才不會突然一堆人守非本職；其他人（板凳、傳奇館、指定打擊）由編號推算。
- 扣分從規則版本 6 起生效（ADR-0003），舊規則存的比賽照舊重播。
