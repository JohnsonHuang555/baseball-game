# V2 Phase 7：競技積分／降級方案的平衡模擬

> 這份報告比較的數字**全部是模擬專用**（`scripts/balance/ranked.ts`），不是正式規則，也沒有寫進遊戲 Config 或存檔。結論與建議值見 [RFC](../phase7-ranked-league-rfc.md)。

## 怎麼跑

```
npm run balance:v2:ranked                                   # 全部方案（約 1.5 小時，2 核心可以分兩個行程跑）
npm run balance:v2:ranked -- --variants=C+3-2 --sessions=3 --strategies=E --seeds=1 --days=20
npm run balance:v2:ranked -- --report=docs/balance/data/phase7-ranked.json   # 只重印表格
```

- 比賽、獎勵、升級、招募、挑戰都由正式服務實際跑（同 Phase 6C 的 `simulate.ts`），積分只記在旁邊的影子狀態；降級時直接把模擬用的記憶體存檔改成下一級。
- 每格 n = 3 種策略（B 平均養成／E 跟著首頁建議／D 招募＋養成，代表弱／中／強球隊）× 3 個固定種子（1、2、3）；45 天；每天上線 1、3、6 次（平均分散）。
- 每天 1 次的有效結算只有 8 小時（96 場），3、6 次是 24 小時（288 場）：上線頻率的差距主要來自場數，所有方案都一樣。

### 方案

| 代號 | 內容 |
|---|---|
| BASE | 現行：100 場＋最近 60 場 60%＋挑戰賽，沒有降級 |
| A+3-2 | 挑戰者以上用積分晉級：≥ 80 ＋ 30 場 ＋ 挑戰賽；勝 +3／敗 −2（設計稿示意） |
| A+2-2 | 同上，勝 +2／敗 −2 |
| A+2-1 | 同上，勝 +2／敗 −1，晉級後保護 40 場 |
| C+3-2 | 晉級維持現行；積分只用來保級，勝 +3／敗 −2 |
| B40 | 晉級維持現行；職業／傳奇每 100 場一季，季勝率 < 40% 降級，晉級後第一季不降 |

共通：積分 0～100、起始與降級後 50、晉級後 20 場保護（A+2-1 是 40）、只有職業／傳奇會降級、挑戰者保底、首次晉級獎勵不重發、挑戰失敗 12 場冷卻。

### 欄位

- **A→B P50**：第一次到 A 到第一次到 B 的天數中位數（只算兩者都到的球團）；括號是到了 A 的球團裡 45 天內到 B 的比例。
- **降級／千場**：該聯盟的降級次數 ÷ 在該聯盟打的一般比賽場數 × 1000。
- **單次上線就被降級**：降級的那一次上線開始時積分還在危險區（> 20）以上的次數 ／ 降級總數（= 一次離線結算就從安全區掉下去）。
- **危險區場數比例**：積分 ≤ 20 的場數比例。

## 解讀

1. **方案 A 的晉級變快很多**：+3／−2 的損益兩平勝率是 40%，現行是 60%。挑戰者→職業 P50 從 3.7 天（每天 3 次）變 1.0 天，每天 1 次從 11 天變 3 天；之後 56% 的球團被降級，B 策略平均 2.6 次。
2. **A+2-2 是隨機漫步**：勝率五成的球隊在職業↔傳奇之間反覆升降，E 策略平均降級 6.3 次、每天 6 次的玩家 78% 被降級；一次上線就從安全區被降級的比例也最高（15／47）。
3. **A+2-1 幾乎沒有降級**，但晉級跟 A+3-2 一樣快，積分沒有實際作用。
4. **C+3-2 的進度與基準完全相同**（晉級規則沒變），45 天只有 B 策略的高頻玩家偶爾降級（11～22% 的球團），每千場 ≤ 0.07 次，危險區場數 ≤ 1%；E、D 沒有任何降級；每天 1 次的玩家完全沒有降級。重返 P50 3.2～6.3 天。
5. **B40（賽季）** 降級比 C 多（每天 6 次 67% 的球團），但因為一季 100 場才判定，不會「一次上線就掉」。
6. **登入頻率差距**：所有方案都由場數決定（每天 1 次的有效場數是 3 次的 1/3）；C 不會擴大差距，A 系列反而讓每天 1 次的玩家更快到傳奇。
7. **長時間離線**：C 的 5 次降級裡有 2 次是一次離線結算（96 場）就從安全區掉到 0。都發生在每天 3 次的 B 策略（每次上線之間隔 8 小時、96 場）。

## 建議值（方案 C）

職業、傳奇有保級積分：0～100、起始 50、勝 +3／敗 −2、歸零降一級、晉級後 20 場保護、降級後 50；晉級規則不變。詳細見 RFC 第 5 節。

## 限制

- 每格只有 9 次模擬（3 策略 × 3 種子），降級是少見事件，比例的誤差很大（尤其 C 的 0～22%）。
- 45 天：每天 1 次的玩家只有 56% 到傳奇，傳奇聯盟長期（60～90 天）的保級壓力還要再跑。
- 降級發生在一批結算的中間時，模擬沒有把剩下的比賽改用新聯盟重打，只是不再計分（正式實作會重新規劃，見 RFC 第 6 節）。
- 策略是腳本化的玩家，不會因為降級而改變行為（例如加碼養成）。
