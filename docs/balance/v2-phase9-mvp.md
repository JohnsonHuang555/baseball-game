# Phase 9 PR 4：單場 MVP 的平衡

- 指令：`npm run balance:v2:mvp`（A 尺度校正、B 得獎分布、C 長期 30／60／90 天、正回饋）。
  - **C 節（PR #23 review 後）就是 `npm run balance:v2:mvp` 預設參數的結果**：四種戰術 × 3 個種子（401／502／603），每一組同時比「沒有 MVP 成長／上限 +0.3／上限 +0.5」，起始球隊相同。
  - A、B 節是第一版用 `-- --games=1000 --seeds=3 --styles=balanced` 跑的 8,000 場（MVP 評選公式沒有改，數字仍然有效；預設 4,800 場的結果投手 26.9%，一致）。
  - 成長速度的對照（每 25、50 次）用 `--perGrowth=25`、`--perGrowth=50`；`--caps=3,5` 指定要比較的上限。
- 效能：`npm run bench:v2:mvp`。
- 「不同聯盟」那一節是加上這一節後用 `-- --games=1000 --skipA --skipLong` 跑的（其他節的數字不受影響）。
- 所有比賽都用固定種子，重跑結果相同；MVP 只看結算後的數據與事件，不影響比賽。

## A. 投手分數的尺度：用「一分的價值」校正，不是湊比例

RFC 的投手方向是「出局 × 聯盟每出局失分 − 自責分 × k」。關鍵是 k 要多大，才能跟打者的分數比較：

- **聯盟每出局自責分**：8,000 場量到 **0.1083**（每 9 局 2.92 分）。用這個值，平均水準的先發得 0 分。
- **打者的一分值多少評分**：每場我方打者評分加總，對我方得分做回歸：評分加總 = −1.66 + **1.47** × 得分（R² 0.76）。
  - RFC 的打者權重是 wOBA 式的尺度（一壘安打 0.9 vs 出局 −0.27，差 1.17），比「一分」大約 1.5 倍。
- **決定**：投手的「少失一分」也值 1.48 評分（`scale = 1480`）。打者多得一分與投手少失一分等值，投手不會因為公式尺度不同而吃虧或佔便宜。
- 三振不另外加分：三振已經反映在出局數與自責分裡，再加會重複計算。

**解讀：**
- **不同聯盟**：投手 23～28%，越高階略高（雙方能力都高、比分較低），都在目標內。
- **投手比例**：全部 26.8%（先發 22.1%、後援 4.7%）。投手強的隊伍（強先發 30.5%、Lv.20 35.1%）比較高，打擊強的隊伍（高長打 23.4%）比較低，方向合理。
- **比賽類型**：低比分（≤ 4 分）投手 60.5%、我方完封對手 78.5%；高比分（≥ 14 分）打者 99.5%；大敗時多半是唯一有表現的打者，後援投手也有 7%。
- **棒次**：1～5 棒 48.3%、6～9 棒 23.6%，前段打席多、自然比較高，但後段也有四分之一。
- **替補**：1.3%（代打全壘打之類的關鍵表現才會拿到）；**後援**：4.7%（長中繼好投、先發提早退場時）。
- **同分**：1.5% 的比賽最高分有兩人以上，跨角色同分 0 次；沒有突出表現（MVP 評分 ≤ 0.5）的比賽 0.5%，照樣依規則選出。

## C. 長期：30／60／90 天（每天上線 2 次；沒有成長／+0.3／+0.5）

每次上線：結算 → 領取 →（特性訓練）→ 平均升級上場球員 → 有資格就挑戰。勝率是快照前 7 天；降級次數是 3 個種子合計；投手 MVP 比例是到快照為止的累計。
「到上限平均天數」是上場球員裡已到上限的人，到上限那天的平均（後來才上場、較少得獎的人會拉高平均）。

**解讀：**
- **平均加成與到上限**：+0.3 時 30 天平均 +0.26，上場 14 人約 12 人已到上限；一天約 192 場，所以大多數先發在 1～2 週內就到 +0.3。之後 MVP 只是榮譽紀錄。
- **晉級**：+0.3 讓「3 個種子都到傳奇」從 51.2 天變成 48.0 天（快 3.2 天、約 6%），+0.5 是 42.7 天（約 17%）。沒有特性訓練時，各戰術到傳奇的種子都只有 1～2 個，天數差異主要是哪個種子到得了，不宜直接比。
- **降級**：有 MVP 成長時降級稍少（均衡型＋訓練：2 → 0），+0.3 與 +0.5 差不多。
- **能力通膨**：90 天上場平均能力 6.05 → 6.13（+0.3）／6.18（+0.5）；+0.3 約等於打者 4 項能力中 1 項 +0.3，Lv.20 的主要能力成長 +2.0 是它的 6～7 倍。
- **集中度**：得獎最多 1 人 18～19%、前 3 人 45～48%，三種設定幾乎一樣；C-3 前 3 人後半段的占比，+0.3 與沒有成長的變化相同（+0.3：−0.3～+4.9 個百分點；沒有成長：+1.0～+4.5）。沒有正回饋壟斷。
- **打者與投手**：長期遊玩的投手 MVP 比例 17～21%，三種設定差不到 1 個百分點（上限不改變角色比例）。這比中性對戰（表 B）的 27% 低，因為長期遊玩裡我方常常比對手強、得分多的比賽打者較容易得獎。
- **升級與特性訓練的相對價值**（均衡型、90 天、最後 7 天勝率，有訓練 − 沒有訓練）：沒有成長 +6.5、+0.3 +6.7、+0.5 +4.9 個百分點。+0.3 時特性訓練的價值跟沒有 MVP 成長時一樣；+0.5 會稍微稀釋。平均等級三種設定都是 19.5～19.7，升級節奏沒有被影響。
- **四種戰術**（沒有訓練、90 天、最後 7 天勝率，沒有成長 → +0.3）：均衡 46.6 → 45.1%、強攻 46.4 → 44.8%、機動 45.8 → 45.8%、守備 47.6 → 49.7%。各戰術的差異在 ±2 個百分點內、方向不一致，跟種子雜訊同一個量級；平均加成都是 +0.26～0.28，沒有哪種風格特別受益。
- **結論**：+0.3 沒有造成明顯失衡。晉級快約 6%、通膨小、沒有壟斷、角色比例與特性訓練的價值都不變。

## 定案：上限 +0.3（PR #23 review）

- **規則**：每 10 次 MVP 自動 +0.1，每位球員合計最多 +0.3（`MVP_CONFIG.maxUnits = 3`）。到 +0.3 後繼續累計生涯次數，照樣能獲選 MVP。
- 單項最終能力上限仍是 10；不改升級、特性訓練的規則；不增加資源獎勵；不改評選公式。成長頻率維持每 10 次。
- 理由：第一版 +0.5 讓晉級快約 17%，+0.3 約 6%，比較符合 MVP「額外獎勵、不是主要養成來源」的定位（C-4）。
- 放慢成長速度（每 25、50 次）沒有用：場數太多，一個月內大家還是會到上限。

## 已知限制

- **勝利打點**只作同分規則，不加分；取得領先的是失誤或雙殺時不記（沒有打點）。
- **觸身球**：引擎沒有這種結果，公式裡照樣有權重但永遠是 0。
- **聯盟每出局自責分**用一個固定值（平均對手 5.8 量測），不分聯盟；各聯盟的投手比例 23～28%，差異不大，所以沒有分聯盟設定。
- **跨角色同分**：打者優先是固定規則；8,000 場裡沒有發生過。
