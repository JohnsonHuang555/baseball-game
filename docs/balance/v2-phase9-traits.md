- 指令：
  - `npm run balance:v2:traits -- --games=1500 --days=45 --seeds=3`：A 是特性效益，B 是長期遊玩。
  - `npm run balance:v2:traits -- --compare --games=1000 --styleGames=1000 --seeds=3 --compareDays=60 --logins=1,2,6 --styles=balanced`
    與 `-- --compare --games=600 --styleGames=200 --seeds=3 --compareDays=60 --logins=2 --styles=power,speed,defense`：C 是上限方案 A／B／C 的比較，D 是先發都練滿時四種風格的勝率。
  - `npm run bench:v2:traits`：離線結算效能。
- 定案參數（`TRAINING_CONFIG`、`MAX_POSITIVE_TRAITS`／`TRAINING_RULES.maxPositive`）：

## 參數是怎麼定的

### 成本（第一版，沿用）

用同一套腳本跑了三組（30 天、2 個種子）：

- **RFC 初值太快：** 一般特性只要 40 場（3.3 小時），一個月內每位先發都練滿；傳奇聯盟也提早約 3 天。問題在成本，不在上限。
- **成本定案的效果：** 每天上線 1～2 次時，到傳奇的時間跟只升級差不多；經驗成本在升級的量級（Lv.10→11 是 6,400 資金、800 經驗），訓練跟升級搶同一份資源。

### 上限：方案 A／B／C（PR #22 review）

- **A**：上限 2、現行成本。**B**：上限 3、現行成本。**C**：上限 3、稀有（金）成本提高到 24,000／4,000／700 場。
- 固定條件：球團種子 301／402／503，同一份腳本、同一個訓練策略（訓練槽空著就挑「A 表效益 ÷ 成本」最高、付得起的一項，只練先發），跟同種子的「只升級」比較。
- 勝率是快照那天之前 7 天的勝率；每天上線 1 次 = 一天 96 場（離線最多算 8 小時），所以「1 次 × 60 天」跟「2 次 × 30 天」的場數相同、結果也相同（可重現性的檢查）。
- 「原生 2 正面的人：多練到第 3 個」是 3 個種子合計：上場球員中原生就有 2 個正面特性的人數，與其中已經練到第 3 個的人數。

#### 解讀與決定

- **長期養成空間：** A 在 30～45 天就碰頂（上場平均 1.74 個正面特性、14 人中約 11 人已滿；原生 2 正面的球員完全沒有成長空間，0/5）。B 到 60 天才接近飽和（平均 2.43 個，約 10 人已滿），原生 2 正面的球員也能練第 3 個（2/5；其餘是訓練策略優先練效益更高的人）。
- **勝率：** 30 天時 B−A 平均約 0 個百分點（−1.4～+2.6，都在雜訊內）；60 天時 B−A 平均 +1.8 個百分點（−1.6～+3.9）。訓練整體比只升級多 +4.5～+9.3 個百分點，跟 A 的 +1.0～+7.6 同一個量級。
- **膨脹上界（D）：** 全隊從 2 個練到 3 個只多 +3.1～+3.9 個百分點（0→2 是 +12.7～+14.3），邊際效益遞減；四種風格的增幅差不到 1 個百分點，沒有某個風格因此失衡。
- **資源競爭：** 60 天的訓練花費 B 是 16.8 萬資金／2.8 萬經驗（A 是 10.4 萬／1.7 萬），約占升級花費的 15%；升級花費只少約 4%。訓練沒有取代升級。
- **晉級時間：** 到傳奇的天數在 3 個種子中只有 1～2 個到得了，平均天數差異（例如防守型 19.0 → 10.8）主要是哪幾個種子到得了，不是穩定的加速；60 天內 A、B 到達的種子數相同。
- **一般 vs 稀有：** 三個方案的稀有（金）完成數都是 0～1。原因是金色特性在 A 表的效益不高（怪力 +0.8、鐵腕 −0.5、終結者 +0.0）而成本是一般的 2.5 倍，訓練策略很少選。**所以 C 跟 B 幾乎一樣**：提高稀有成本擋不到第三個名額。
- **決定：採用 B（`MAX_POSITIVE_TRAITS = 3`、成本不變）。** 如果之後要壓長期膨脹，不建議降回 2，也不建議只漲稀有成本（C 證明無效）；建議改成「第 3 個正面特性的訓練成本或所需場數 ×1.5」這類提高第三個名額門檻的做法。

### 潛能池能不能撐到第 3 個

- 潛能池用 Lv.1 原始資料，升級不變（測試：`潛能池不會整個卡死`）；已經學到的特性留在池裡顯示「已擁有」。
- 用 4 個球團種子 × 1,000 名打者＋1,000 名投手（8,000 人）統計「原生負面都改善後，依潛能池能到幾個正面」：**100% 都能到 3 個**，包括原生 2 正面（808 人）與原生 0 正面的人。
- 原生負面都改善後，還沒到上限的球員一定至少有一項能學（800 人抽樣 0 例卡死）。
- 沒有修改既有的潛能池。介面仍保留說明：如果某位球員的潛能池到不了上限（已經擁有或彼此互斥），特性養成區會寫出他最多能到幾個；已滿時寫「之後只能改善負面特性」。

訓練設定：common 6000／1000／200 場、rare 15000／2500／500 場、improve 8000／1200／300 場

**解讀：**
- **投手特性效益最大**：奪三振、滾地球、危機處理各約 +2～3 個百分點；改善四死球 +4.8、被全壘打 +2.3。原因是 V2 的先發投手每場都投。
- **打者的單一特性**：大多在 +1 個百分點以內，只影響一位打者的 4～5 個打席。
- **沒有可測量效果的特性：**
  - **觸擊○**：只有教練實際會叫他觸擊（打擊＋長打 ≤ 10 的弱打者、後段）才有用；第 3 棒從來不觸擊，所以是 0。
  - **好手套**：單一守位、單一場的影響很小。
  - **體力差（改善）**：引擎確實會讓疲勞門檻 −15 球，但 V2 的自動教練依疲勞門檻換投，所以改善後的效果是先發多投幾球、少用牛棚，勝率幾乎不變。
  - 以上照實標記在已知限制；這些特性仍可訓練（引擎裡確實有作用），但玩家應該知道效益偏小。
- **Lv.1 與 Lv.20**：同一個特性的效益差不多（訓練成本固定，不隨等級變貴）。
- **戰術風格**：跑壘、長打相關特性在四種風格下的差異都在誤差內，沒有讓某個風格明顯失衡。

- **完成所需的真實時間**：一般 16.7 小時、稀有 41.7 小時、改善 25 小時（以球員每場出賽計）。45 天內完成 13～26 項，每天上線 1 次明顯較少；不是一週內練完全隊。
- **花費**：45 天約 9～16 萬資金、1.4～2.7 萬經驗，是升級花費的 12～24%。
- **勝率**：最後 7 天勝率高 2.8～8.2 個百分點（每天上線越多越高）；上限 3 與 2 的比較見上面的 C。

- **上限是否合理**：見上面的 C。上限 3 時，45 天後還有養成空間，60 天才接近飽和。
- **負面特性改善是否太划算**：改善四死球（+4.8）的效益最高，但成本也較高（8,000／1,200／300 場），而且只有原生帶四死球的投手才有；平均每支隊伍不到一位這樣的投手。
