# 骰子棒球：roguelike 改版的畫面設計需求

## 這次要做什麼

骰子棒球是手機網頁棒球遊戲。玩家扮演教練，平常看球員自動比賽、下戰術指令，遇到關鍵打席才親自出棒或配球。整體視覺已經定案，規範見 [design-brief.md](design-brief.md)：深藍底、卡牌手遊風、粗黑邊框、黃色主按鈕、S～G 字母等級、銅／銀／金／彩虹卡色。

這次改版把錦標賽改成 roguelike 的「一輪」，球隊一場場打上去越變越強，並新增了休息站、球團史、自由練習。**功能都已完成、可以運作，但新畫面是工程師沿用舊元件拼出來的。請沿用現有的視覺語言，重新設計下面列出的新畫面與新元件，不要改玩法。**

附件截圖是目前的實際畫面（編號對應下方各節），可以當作「現在長怎樣、有哪些資訊」的參考，版面與視覺都可以推翻。

## 設計目標（依重要程度）

1. **拿到東西要爽**：獎勵卡、覺醒、奪冠是這次改版的情緒高點，要有抽卡、升級的驚喜感。
2. **一眼看出變強了**：秘寶、裝備、潛能、球種特性疊在球隊上，玩家要能一眼看懂「我這隊有什麼」。
3. **選擇時知道代價**：商店價格、事件的代價、能不能學（以及為什麼不能）要清楚。
4. **一輪的節奏感**：例行賽 → 季後賽 → 奪冠，玩家要隨時知道自己在哪、還差多少。

## 硬性限制

- **兩種版面**：手機直式以 390 × 844 為基準（最小 375 × 667，最大寬 480）；電腦版以 1440 × 900 為基準。兩種都要出圖。
- 繁體中文，**不使用 emoji**，所有圖像用 CSS 或 SVG 畫，不依賴插畫與照片。
- 按鈕高度至少 44px，手機版的主要按鈕放在拇指點得到的下半部。
- 名字長度：中文 3～4 字，英文最長約 14 字元（Carlos Martinez）；隊名最長 10 字。
- 沿用既有的顏色語意：我方藍、對手橘；S～G 等級色；銅／銀／金／彩虹卡色；金特黃、藍特藍、紅特紅。
- 難度標籤顏色：新人綠、職業藍、明星紫、傳奇橘、名人堂金。

## 名詞（畫面上的用字請照這份）

| 名詞 | 意思 |
|---|---|
| 一輪 | 從開新錦標賽到奪冠或被淘汰 |
| 例行賽 | 8 場，至少 5 勝晉級季後賽，第 4 敗就淘汰 |
| 季後賽 | 八強、四強各一場，決賽三戰兩勝；例行賽勝場越多種子越前面、對手越弱 |
| 獎勵選擇 | 每場比賽後挑一張卡：贏球 3 選 1，輸球 2 選 1，也可以放棄 |
| 秘寶 | 全隊共用的被動效果，整輪有效，例如「得點圈之魂：得點圈有人時全隊打擊 +1」 |
| 裝備 | 掛在單一球員身上的道具，每人最多 2 件，例如「碳纖釘鞋：速度 +2」 |
| 背包 | 還沒裝在任何人身上的裝備 |
| 潛能 | 球員身上的「？」，只看得到條件和進度（例如「？ 全壘打 2/4」），看不到會得到什麼 |
| 覺醒 | 潛能條件達成，「？」變成真正的特性 |
| 球種特性 | 加在某位投手某個球種上：銳利、尾勁、精準，名稱接在球種前面，例如「銳利滑球」 |
| 新球種 | 讓投手學會原本不會的變化球 |
| 休息站 | 例行賽第 2、4、6、8 場之後，從商店、訓練、事件三選一 |
| 球團資金 | 一輪內的錢，比賽賺、商店花；釋出球員換回身價一半 |
| 關鍵打席 | 系統讓教練親自出手的打席：英雄時刻、滿壘危機、差一步覺醒、一分差二三壘有人 |
| 球團史 | 跨輪紀錄：冠軍、傳奇館、歷程、衣櫃 |
| 傳奇館 | 奪冠後可送一位球員進去；之後開新錦標賽可帶他加入（能力每項 −1） |
| 自由練習 | 只打一場、不記錄結果的沙盒，可以自己組隊、改能力 |

## 畫面清單

### 1. 錦標賽主畫面（最重要；截圖 01、02）

兩場比賽之間的中樞。

- 頂部：返回、隊名、難度標籤、**目前資金**
- **例行賽進度**：8 格，每格是勝（比分）、敗、下一場（高亮）、還沒打（對手名稱淡色）四種狀態之一；旁邊顯示戰績「2 勝 1 敗」與「還差 3 勝晉級季後賽・還能輸 2 場」
- **季後賽**：八強 → 四強 → 決賽三格，還沒打到的不顯示對手；晉級後顯示「第 2 種子」；決賽顯示系列賽比數
- **秘寶**：帶卡色的標籤，名稱加一行效果
- **身上的裝備**、**背包**：點背包裡的裝備會選人裝上，點身上的裝備會卸下
- 按「調整陣容並開賽」進到佈陣畫面後，點任一球員的詳細資料（底部面板）也有裝備區：身上的裝備（1/2）可以卸下，背包裡他能帶的可以裝上，裝滿時要選換下哪一件
- 底部：下一個對手（雙方隊名、總評）與「調整陣容並開賽」

需要的狀態：剛開打（沒有戰績、只有 1 個秘寶、背包空）、例行賽中段、季後賽中、決賽系列賽 1-1。

### 2. 起始秘寶（截圖 03）

開打後的第一個畫面，從 3 個秘寶中選 1 個（不會出現彩虹卡）。選了之後按「收下秘寶 ○○」。

### 3. 獎勵選擇（第二重要；截圖 04、05、06）

每場比賽後出現，標題依情況是「贏球獎勵」「輸球獎勵」「晉級季後賽！」。

**六種獎勵卡**，都用卡色（銅、銀、金、彩虹）當外框，請讓種類一眼可分：

| 種類 | 卡上內容 |
|---|---|
| 球員 | 頭像、總評、慣用手、擊球方向或球種、能力長條、第一個特性；**可能帶潛能「？ 安打 0/7」** |
| 裝備 | 圖示（球棒、釘鞋、手套、止滑粉袋、護腕五種）、名稱、打者用或投手用、效果「打擊 +2・力量 +2」 |
| 秘寶 | 圖示、名稱、效果 |
| 特性 | 特性標籤（金或藍）、打者用或投手用、一句說明 |
| 球種特性 | 名稱「銳利滑球」、投手用、說明，固定銀卡 |
| 新球種 | 名稱「指叉球」、投手用、說明，固定金卡 |

選一張卡後，旁邊（手機版是下方）列出要交給誰：

- 球員卡：同角色的每一位球員，按鈕「換掉」；被換下的人會換回資金
- 裝備：能帶的球員和他現在的裝備；裝滿 2 件時按鈕變成「換下 ○○」；另有「先放進背包」
- 特性：同角色的每一位球員**和他已經會的特性**；不能學的按鈕停用，並寫明原因（「已經會了」「特性已滿」）
- 球種卡：每位投手和他會的球種；不能學的寫明原因（「已經會了」「不會這個球種」「這個球種已有特性」）
- 秘寶：直接「收下秘寶 ○○」

底部「放棄這次獎勵」。需要彩虹卡與金特的翻牌特效。

### 4. 休息站（截圖 07～10）

- **選地點**：商店、訓練、事件三張大卡，各一個圖示與一句說明；右上角顯示資金
- **商店**：6 格商品（2 名球員、2 件裝備、1 個秘寶、1 張特性或球種卡），每格是商品卡加上「買下・55」價格按鈕；錢不夠時停用，買過的顯示「已售出」。另有三個動作：「付費強化・40」（越強化越貴）、「換一批商品・20」、「離開商店，前往下一場」
- **訓練**：選一位球員，再選一項能力 +1。選能力時要顯示提升前後的字母（例如「打擊：C → B」）；有潛能的球員訓練會推進進度
- **事件**：圖示、事件名稱、一段情境、兩個選項；選項可能標著「花 40 資金」，錢不夠時停用。8 個事件見文末範例

### 5. 潛能、覺醒、球種特性的呈現（新元件）

- **潛能標籤**：特性標籤的「未定」版本，目前是紫色虛線框「？ 全壘打 2/4」。要讓人一看就知道「還沒揭曉、有進度」。會出現在獎勵卡、打序表、球員詳細資料
- **覺醒提示**：比賽結果畫面多一行「覺醒！李哲瑋 獲得『怪力』」，希望有特效
- **球種特性**：在球種列（直球、滑球、曲球……）上標出帶特性的球種；配球面板（親自投球時選球種）上要有「銳利」這類小標籤；配球面板最多 5 個球種
- **關鍵打席提示**：比賽中觸發時的大字提示，四種文案見文末

### 6. 錦標賽結束（截圖 11、12）

- 奪冠：獎盃、光芒與紙花（現有）、解鎖的裝扮與下一級難度（現有）
- **新增「送一位球員進傳奇館」**：列出整隊 14 人（頭像、名字、總評），點一位就送進去，之後改成一句「○○ 進入傳奇館」
- **新增「奪冠回顧」**（目前是彈出視窗）：秘寶組合、每一場（階段、勝敗、比分、對手、MVP）、覺醒紀錄（「第 5 場後・李哲瑋 覺醒『怪力』」）、每位球員從開打到奪冠的總評變化（字母 → 字母、+1.3），進步最多的排前面
- 淘汰：「止步八強」之類，加上這一輪的戰績

### 7. 球團史（截圖 13～16）

從首頁進入，四個分頁：

- **冠軍**：每座冠軍一張卡（難度、隊名、日期、決賽比分、先發頭像），點開看奪冠回顧；改版前的獎盃沒有回顧資料
- **傳奇館**：每位傳奇一張卡（頭像、名字、打者或投手、出身「芝加哥流星・職業冠軍」、能力字母、特性）
- **歷程**：每一輪一列，**包含被淘汰的**：難度、隊名、結果（奪冠／止步四強）、戰績、日期、秘寶組合；奪冠的列要突出
- **衣櫃**：6 款裝扮（標準、條紋球衣、金色球帽、墨鏡、冠軍皇冠、黃金戰袍），已解鎖可換、未解鎖寫「通過『明星』解鎖」、使用中要標示

### 8. 首頁

- 按鈕改為：自由練習、錦標賽（或繼續錦標賽／新的錦標賽）、「球團史・1 座冠軍」
- 左上角只剩頭像的貓咪／小狗切換（裝扮搬進衣櫃了）
- 開新錦標賽時：先選難度；傳奇館有人的話，接著問「帶一位傳奇加入？」（可以不帶）

### 9. 自由練習（截圖 17～19）

- **練習選單**：「我方」「對手」兩欄，各自從「隨機球隊」與自製球隊中選一個；對手的隨機選項可選強度（新人～名人堂）。下方「我的球隊」列出自製球隊（編輯、刪除），以及「新建球隊」「匯入冠軍隊伍」；主要按鈕「開始練習」
- **編輯球隊**（修改自動存檔）：隊名輸入、12 個秘寶的開關、14 位球員列表（點一下編輯）、「調整打序與守位」「加入傳奇館球員」
- **編輯球員**（目前是彈出視窗）：名字；慣用手（右打／左打／兩打，或右投／左投）；擊球方向（偏左／平均／偏右）；能力滑桿 1～10、每格 0.5，旁邊即時顯示字母；特性開關（最多 3 個，互斥的會互相取代，滿了其他的停用）；裝備兩格下拉；投手另有「新球種」開關與每個球種的「球種特性」下拉

### 10. 對手陣容（截圖 20）

佈陣畫面右上角的對手標籤可以點，彈出對手完整陣容：打序（棒次、守位、左右打、四項能力字母、特性）、投手（先發、後援）、板凳，欄位上方標「打 力 速 守」或「威 控 耐」。

## 圖示清單（都要 SVG）

- 裝備五種：球棒、釘鞋、手套、止滑粉袋、護腕（截圖 21 是目前的樣子）
- 秘寶（寶石）、特性（星星）、球種特性（棒球加速度線）、新球種（棒球加一個加號）
- 休息站三個地點：商店、訓練（啞鈴）、事件（問號）
- 資金（目前只有「資金 200」文字標籤，可以加圖示）

## 範例資料

- 隊名：芝加哥流星、高雄鐵騎、台北飛鷹、波士頓海盜
- 秘寶：守護神（金卡，第 9 局起我方投手球威 +1.5）、得點圈之魂（銀卡，得點圈有人時全隊打擊 +1）、開路先鋒（銅卡，每個半局第一位打者打擊 +2）、王朝（彩虹卡，全隊打擊、力量、球威、控球都 +0.5）
- 裝備：練習球棒（銅，打擊 +1）、碳纖釘鞋（銀，速度 +2）、金手套（金，守備 +2・打擊 +1）、傳說球棒（彩虹，打擊 +2・力量 +2）、精準臂套（銀，控球 +2，投手用）
- 潛能：「？ 全壘打 2/4」（覺醒成怪力）、「？ 安打 0/7」、「？ 三振 11/18」
- 事件：球迷見面會、地下特訓、名投手教練來訪、加練到深夜、贊助商上門、二手球具市集、神祕老人、復健中心。例如「贊助商上門：一家飲料公司開出不錯的條件，但代言行程很操。」選項「簽約：資金 +80，但隨機一位球員染上一個紅特」「婉拒」
- 關鍵打席提示：「英雄時刻！一支安打就能改寫比分」「滿壘危機！這個打席由你配球」「差一步！這個打席有機會讓球員覺醒」「一分差、二三壘有人！」
- 錦標賽主畫面情境：職業難度、例行賽 6 勝 2 敗晉級、季後賽第 3 種子、資金 185、秘寶 3 個、背包 2 件

## 希望拿到的東西

1. 上述畫面的設計稿，手機（390 × 844）與電腦（1440 × 900）各一份，含主要狀態
2. 新元件規格：六種獎勵卡、潛能標籤、商品格（含價格與已售出）、例行賽格子、季後賽格子、秘寶與裝備標籤、事件選項、分頁
3. 動畫說明：獎勵卡翻牌（含彩虹卡、金特）、覺醒、奪冠、送進傳奇館
4. 如果可以，提供 HTML／CSS 原型，方便直接對照實作

## 不需要

- 比賽畫面、決策面板、組隊畫面的重新設計（已定案，只需要上面提到的局部新增）
- 音效
- 新的玩法或功能（如果覺得哪裡缺功能，請另外列建議）
