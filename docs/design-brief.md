# 骰子棒球：視覺設計需求

## 這是什麼遊戲

手機網頁棒球遊戲。玩家扮演**教練**，不操控球員動作：比賽前隨機抽到一支球隊，可以重骰、調整打序與守位；比賽中以上帝視角看球員自動投球、打擊、跑壘，只在關鍵時刻下戰術指令（盜壘、代打、換投等）。有「快速比賽」（打一場）與「錦標賽」（16 隊淘汰，贏球可以選秀補強）兩種模式。

目前功能都已完成，畫面可以運作，但視覺是工程師拼出來的。**這次要做的是整體視覺設計，不改玩法。**

## 設計目標（依重要程度）

1. **有遊戲感**：看起來像手遊，不像管理後台。
2. **一眼看懂，文字少**：能用圖像、顏色、字母等級表達的，就不要用句子。
3. **決策時知道該看哪裡**：關鍵時刻的面板要讓玩家在 3 秒內看懂局勢與選項的差異。
4. **抽卡的爽感**：抽到稀有球員（彩虹卡、帶金特）要有明顯的驚喜感。

## 風格方向

（請在這裡填入你想要的方向，例如以下其中一種，或自己描述）

- 電視轉播風：比分條、轉播字幕感、俐落的運動感
- 卡牌收集風：球員卡是主角，像實體球員卡或手遊抽卡
- 復古球場風：懷舊色調、記分板、手寫字
- 參考作品：野球魂（パワプロ／プロスピ）、MLB The Show 的介面

目前的畫面是深藍底色，可以完全推翻。

## 硬性限制

- **平台**：手機直式網頁，以 390 × 844 為基準，也要能縮到 375 × 667（iPhone SE），最大寬度 480。不需要橫式或桌機版。
- **語言**：繁體中文。
- **不使用 emoji**。符號可以用（例如 ○ ×），但不要 emoji 圖示。
- **沒有美術素材**：所有圖像要能用 CSS、SVG 或 Canvas 畫出來。不要依賴插畫或照片。
- **球員頭像要能程式產生**：球員是隨機產生的，頭像由「膚色、髮型、鬍子、表情、帽子顏色」等部件組合而成，同一名球員永遠長一樣。請設計**部件的風格與變化**，而不是單張頭像。
- **名字長度不一**：中文 3～4 字（陳建宏、渡邊悠斗），英文最長約 14 字元（Carlos Martinez）。卡片要能容納或優雅地截斷。
- **比賽中的球場是 Canvas 2D 動畫**：俯視角，守備員和跑者是圓點，球是白點，會飛行、跑壘。可以設計配色、圓點樣式與球場畫法，但要保持簡單。
- **手機操作**：重要按鈕在畫面下半部、拇指點得到；按鈕高度至少 44px。

## 必須保留的顏色語意

| 語意 | 規則 |
|---|---|
| 我方 vs 對手 | 全遊戲統一用兩種顏色區分（目前藍和紅）：帽子、場上圓點、頭像外框都遵守 |
| 能力值等級 | S、A、B、C、D、E、F、G 八級，S 最強；每級一個顏色，S 要特別華麗。D 是平均水準 |
| 球員卡色 | 依總評分成銅、銀、金、彩虹四級，彩虹最稀有 |
| 特性 | 三種：金特（強力稀有）、藍特（一般正面）、紅特（負面），用顏色區分的小標籤 |

色弱友善：等級除了顏色也要有字母；我方與對手不要只靠紅綠區分。

## 畫面清單

每個畫面請以 390 × 844 出圖。範例資料見文末。

### 1. 首頁
- 遊戲標誌、名稱「骰子棒球」、一句副標題「你是教練。隨機發一支球隊，剩下的交給你的判斷。」
- 按鈕：快速比賽、錦標賽；有進行中的錦標賽時，多一顆「繼續錦標賽（八強）」，原本的錦標賽按鈕變成「新的錦標賽」

### 2. 組隊畫面（最重要）
快速比賽開打前、錦標賽開打前使用。
- 頂部：返回、隊名（可自訂）、整隊總評等級（大字母）
- 「改隊名」「隨機隊名」兩個小按鈕
- 對手名稱與對手總評
- **球場圖**：9 個守位上各放一名球員（頭像、名字、總評字母、打序號碼 1～9）；投手丘是先發投手；指定打擊放在本壘旁，標註「指定打擊」
- 板凳 2 人、後援投手 2 人：小卡
- **打序列表**：1～9 棒，每列有棒次、頭像、名字、守位、四個能力字母（打、力、速、守）；填滿剩餘空間，可以捲動
- 底部固定：「整隊重骰（剩 3 次）」「開始比賽」

需要的狀態：
- 交換模式：選了第一名球員後，他被高亮，底部提示「選擇要和 ○○ 交換的球員」「點球場上的人交換守位，點打序列表交換棒次」與「取消」
- 重骰後的翻牌動畫；稀有球員的特殊動畫
- 改隊名的輸入狀態

### 3. 球員詳細資料（從底部滑出的面板）
- 大頭像、卡色外框、名字、位置與棒次（例如「打序 1・捕」）、總評大字母
- 能力值：打者四項（打擊、力量、速度、守備），投手三項（球威、控球、體力），每項有字母與長條
- 特性標籤與一句說明（例如「得點圈強打：得點圈有人時打擊提升」）
- 按鈕：交換、重骰此球員（剩 5 次）、關閉；比賽之間的陣容調整沒有重骰

### 4. 比賽畫面
- 頂部比分條：兩隊名稱與比分、目前進攻方標示、局數（例如「7 局下」）、好球／壞球／出局燈號
- 俯視球場動畫（Canvas）
- 打者 vs 投手資訊：頭像、名字、能力字母；投手用球數與疲勞警示
- 最新一球或一個打席的結果文字（例如「游擊方向滾地球，形成 6-4-3 雙殺」）
- 控制列：「指令」（主動暫停）、速度 1x／2x／4x、「決策提示：少」切換
- 比賽紀錄（可捲動的文字列表）
- 球場上的大字提示：「滿貫全壘打！」「6-4-3 雙殺！」「失誤！」「得 2 分」

### 5. 決策面板（第二重要）
從底部滑出，三種標題：「關鍵時刻！」「投手體力下滑」「教練暫停」。
- 局數、出局數、比分；小壘包圖，有人的壘包亮起；壘上情況文字（例如「滿壘」「一、三壘有人」）
- 打者 vs 投手對決區：頭像、能力字母、投手體力條
- **最多 3 個重點選項**，每個只比一兩個關鍵數字，例如：
  - 代打 山田直樹：打擊 C → B、力量 F → D
  - 盜三壘 李子軒：速度 C、成功率約 61%
  - 換投 楊建宏：體力 0% → 100%、球威／控球 B／C
  - 守備替補 左外野 林品睿 → 陳家豪：守備 E → B、打擊 B → E
- 「其他指令」「詳細資訊」兩個可展開區塊（展開後列出所有可下的指令、所有相關球員的能力）
- 主要按鈕「交給球員」
- 沒有重點選項時的空狀態

### 6. 比賽結果
- 勝利／落敗大標題
- 每局比分表（1～9 局，延長賽會更多欄；九局下沒打顯示 X）
- 按鈕：快速比賽是「再來一場」「回首頁」；錦標賽是「繼續」

### 7. 錦標賽主畫面
- 下一個對手卡片：輪次（十六強、八強、四強、決賽；決賽顯示「決賽 第 2 戰（系列 1-0）」）、對手名稱、雙方總評、按鈕「調整陣容並開賽」
- 戰績列表：每場的輪次、勝敗、比分
- 賽程樹：十六強 8 場、八強 4 場、四強 2 場、決賽 1 場；勝者、敗者、自己的隊伍要能區分；還沒打到的輪次顯示「待定」
- 奪冠與淘汰的結束狀態：「奪冠！」或「止步八強」，加一句「這支隊伍的旅程結束了，下次會是全新的隊伍。」

### 8. 選秀
- 標題、說明「贏球了！從 3 名球員中挑 1 名加入隊伍，或放棄這次選秀」
- 3 張候選球員卡：頭像、總評、能力長條、特性說明，有翻牌動畫
- 選了一名後，下方列出可以被替換的同角色球員（打者換打者、投手換投手）
- 「放棄選秀」

### 9. 共用元件
- Toast：每次決策後在畫面下方短暫出現，例如「郭志明 與 陳家豪 交換守位」「已下達：盜二壘，下一球執行」
- 按鈕：主要、次要、外框、小型切換 chip、停用狀態
- 能力字母徽章：小、中、大三種尺寸
- 特性標籤：金、藍、紅三色

## 範例資料

- 隊名：新竹風城、台北雄獅、東京海盜、波士頓雷霆
- 球員：陳建宏（打 B、力 D、速 E、守 C，特性「得點圈強打」）、山田翔太（打 A、力 S、速 F、守 D，金特「怪力」，彩虹卡）、Carlos Martinez（打 E、力 C、速 A、守 B，特性「盜壘○」「扇風機」）
- 投手：Ryan Smith（球威 B、控球 E、體力 C，特性「奪三振」「四死球」）
- 比賽情境：8 局下、2 出局、滿壘、比分 3:4 落後，打者打擊 F

## 希望拿到的東西

1. 上述每個畫面的設計稿（390 × 844），含主要狀態
2. 設計規範：顏色（含等級、卡色、特性、我方與對手）、字型與字級、間距、圓角、陰影
3. 元件規格：球員小卡、球場守位節點、打序列表列、重點選項卡、字母徽章、按鈕、toast
4. 動畫說明：翻牌、稀有卡特效、面板滑出、toast、比賽中的大字提示
5. 如果可以，提供 HTML／CSS 原型，方便直接對照實作

## 不需要

- 橫式、平板、桌機版面
- 音效
- 登入、帳號、商城、付費相關畫面
- 新的玩法或功能（如果覺得某個畫面缺功能，請另外列出建議，不要直接畫進設計稿）
