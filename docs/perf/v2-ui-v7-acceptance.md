# V2 介面改版（v7）效能與版面驗收

腳本：`scripts/ui-acceptance.py`（先 `npm run build`；需要 Python Playwright 與 Chrome）。
測試存檔：打了 3 小時（36 場）、領過收益的球團，約 59 KB。存檔比瀏覽器時間落後約 1 小時，所以開啟時會先結算約 12 場離線比賽。

- **手機**：390×844、DPR 2、觸控，CPU 降速 4 倍。
- **電腦**：1366×900、DPR 1，不降速。

每種尺寸各跑一般與「減少動態效果」（`prefers-reduced-motion: reduce`）兩次。本機靜態伺服器、字型請求擋掉，數字只適合拿來比較，不代表真實網路環境。

## 播放流暢度

用 requestAnimationFrame 量每一格的間隔。陣容一邊捲動一邊量 60 格；直播播放中量 120 格。兩種尺寸都是 p50／p95／最大 17 ms，60 fps、沒有掉格。

- **Long task**：手機 4× 降速時有 12～13 個，最長約 200 ms，都在開啟時的離線結算（模擬比賽）期間。電腦只有 1 個，約 55～70 ms。

## 版面檢查（四種組合全部通過）

- **首頁**：直播卡有比分列。捲到底時，最後一個按鈕在底部導覽上方。
- **陣容**：捲到底時，最後一列的「養成」在底部導覽上方。
- **未儲存草稿**：儲存列浮在底部導覽上方，「儲存陣容」在畫面內。
- **球員養成**：升級按鈕固定在面板底部、在畫面內。
- **招募**：三張候選卡（手機直排、電腦三欄），「確認簽約」在畫面內。
- **直播 Canvas**：
  - 手機 CSS 366×300、實際 732×600（DPR 2）；電腦 918×753。
  - 都有畫出內容。
  - 底部控制在畫面內。
- **減少動態效果**：
  - 觀戰畫面加上 `reduced-motion`。
  - 閃光層不顯示（`display: none`）。
  - 首頁直播圓點的動畫：一般是 `v2-live-blink`，減少動態時是 `none`。
- **錯誤**：沒有任何頁面錯誤。
