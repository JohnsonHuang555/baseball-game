## 2. 統計正確性（不變量，160 場 × 兩隊）

- 每位打者：`PA = AB + BB + HBP + SF + SH`、`H ≥ 2B + 3B + HR`、`IBB ≤ BB`、`HBP = 0`（引擎沒有觸身球）。
- 打者 H 加總 = 記分板 H；打者 R 加總 = 比分；PA／H／HR／RBI／SO 與舊 PlayerLine 完全一致。
- 投手 R 加總 = 對手得分；每位投手 `ER ≤ R`、`HR ≤ H`；K 加總與舊 PlayerLine 相同；BF 加總 = 對手 PA 加總。
- 投手 Outs 加總 = 守備的出局數（主隊 `3 × 局數`；客隊依是否再見結束），包含盜壘刺殺。
- 沒有失誤、沒有延長賽的比賽 ER = R；有非自責分的比賽確實存在。
- 單元測試：ROE、延長的半局、繼承跑者、後援不享有前一位的失誤機會、打席中途換投的保送、代打兩好球三振、代跑承接、延長賽二壘跑者、盜壘刺殺的出局、第三出局那一球的得分。

## 3. 生涯與期間

`src/v2/application/playerStats.test.ts`、`src/v2/infrastructure/migrationV10.test.ts`：

- 連續 96 場離線結算：生涯 = 每場 lines 加總；每場打者得分＝我方得分、投手失分＝對手得分。
- 重送同一場、多分頁同時結算、分兩次結算（中間換分頁）：生涯完全相同、沒有重複。
- 離線中途降級（傳奇 → 職業 → 挑戰者）：降級前後的比賽都累積，沒有漏掉。
- 升級、換陣容：同一個 playerId 繼續累積。
- 釋出：紀錄保留並標記，排行不列、戰報與詳情仍找得到名字。
- 最近 10／30 場的範圍、沒上場不增加 G、近期與生涯共用同一組公式。
- V9 → V10：記錄起點＝當時游標；其他欄位一字不動；舊比賽沒有 lines；之後的比賽開始累積。

## 8. 已知限制

1. ROE 那一球的得分不給打點、一律非自責；ROE 造成的額外推進不另外重建（ER 可能略多）。詳見規格 §6。
2. 引擎沒有觸身球、野選、暴投、捕逸：HBP 永遠 0。
3. 勝敗投、救援、盜壘數、守備數據不在本階段。
4. Phase 8 之前的比賽沒有個人數據，不回填。
5. 同名球員（隨機產生的名字可能重複）在戰報裡以 playerId 區分，名字本身相同。
